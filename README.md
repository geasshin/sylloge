# Bibliothèque culturelle, V0.1

Prototype local React d'une bibliothèque culturelle personnelle. Cette V0.1 conserve le socle calme de la première version, réserve Syne aux grands titres et ajoute le rayon Séries avec ses fiches.

```bash
npm install
npm run dev
```

Pour vérifier la version de production :

```bash
npm run build
```

Pour contrôler les types et les parcours Films et Séries :

```bash
npm run typecheck
npm run verify
```
