# Itération UX 0.3.2 — mapping lisible et parcours modaux

## Décision issue de la QA

Le comportement d’import est fonctionnel, mais l’interface actuellement rend la décision de mapping illisible : elle affiche les propriétés de destination Sylloge comme libellés de champs et les colonnes source comme valeurs de sélecteurs. Elle mélange donc deux questions différentes : « qu’est-ce que Sylloge a détecté dans le fichier ? » et « dans quelle propriété Sylloge faut-il l’importer ? ».

La capture révèle aussi un problème de navigation réel : la sidebar indique `Profils`, mais l’import puis les sauvegardes se succèdent dans la même longue page. Les sections sont seulement des ancres, pas des pages indépendantes. Enfin, les parcours Importer/Exporter déplient des contenus lourds sous leurs boutons au lieu d’ouvrir un espace de travail dédié.

## Périmètre

Il s’agit d’une correction d’UX du jalon `0.3.2`, limitée aux réglages et aux flux de portabilité Films. Aucun changement SQLite, format, dépendance, média, version ou API.

## 1. Pages de Paramètres réelles

- `Profils`, `Importer et exporter`, `Sauvegardes`, `Application`, `À propos` affichent chacune leur propre contenu ; sélectionner une entrée ne déclenche plus de défilement d’ancres ni l’affichage des autres catégories sous la première.
- La sidebar reste la navigation locale des Paramètres et conserve le retour explicite à la bibliothèque.
- Les actions de processus (imports, exports et confirmations associées) s’ouvrent dans un espace modal grand format, pas sous les cartes de réglages.

## 2. Hub Importer et exporter

- La page ne montre qu’une introduction courte et les deux intentions `Importer` / `Exporter`.
- Chaque intention ouvre un assistant modal : choisir le type, choisir le fichier ou le format, vérifier, confirmer. Les résultats restent dans le modal jusqu’à fermeture explicite.
- Les formats expliquent leur destination humaine : bibliothèque Sylloge complète JSON, bibliothèque Films externe CSV/Notion, sauvegarde Sylloge JSON, tableau Films CSV.

## 3. Assistant de mapping CSV / Notion

Après lecture d’un fichier Films, afficher un assistant modal en étapes, sans écriture avant la dernière confirmation :

1. **Source** : fichier et table retenue, avec libellés courts dépourvus de chemins/UUID techniques ; le choix d’une autre table reste possible si nécessaire.
2. **Mapping** : tableau à trois colonnes visuellement explicites :
   - `Détecté dans votre fichier` : chaque colonne source, y compris celles actuellement ignorées ;
   - flèche ;
   - `Importer dans Sylloge` : sélecteur de destination ou `Ne pas importer`.
3. **Aperçu** : profil créé, compteurs, avertissements et confirmation.

Le mapping est pensé dans le sens **source → propriété Sylloge**, même si le modèle domaine conserve sa forme interne destination → source.

- Une source ne peut être envoyée que vers une destination, et une destination ne peut recevoir qu’une source. Un changement résout proprement l’ancien choix ; le domaine refuse aussi les duplications invalides.
- Chaque destination affiche un vocabulaire non ambigu : `Évaluation` pour une note chiffrée normalisée vers `/5` ; `Note personnelle` pour du texte libre. Une colonne de notation ne devient jamais une note personnelle.
- Les pages Notion `Notes` sont explicitées comme contenu texte associé séparément ; elles peuvent alimenter `Note personnelle` ou être ignorées, mais ne sont jamais confondues avec l’évaluation numérique.
- La détection automatique est signalée comme proposition et le sélecteur est clairement identifié comme réglage modifiable. Les colonnes non reconnues apparaissent avec `Ne pas importer` par défaut, plutôt que seulement dans un paragraphe final.
- L’échelle `/10` détectée explique la conversion vers l’échelle Sylloge `/5` par demi-points.

## Acceptation

- Les cinq boutons de la sidebar Paramètres montrent chacun une seule page, sans défilement vers les autres réglages.
- Un import ou export n’agrandit pas la page de réglages : il ouvre un dialogue grand format accessible et fermable.
- Avec l’archive Notion de QA, le tableau de mapping distingue la colonne source `Note` de la destination `Évaluation`; `Note personnelle` est réservée au contenu Markdown associé, jamais mappée à `Note`; l’aperçu reste 401 convertibles, 0 erreur, `/10` détecté et 25 notes Markdown.
- Un mapping dupliqué manuel ne peut pas conduire à une importation ambiguë.
- `npm run typecheck`, `npm run verify`, `npm run build`, `cargo fmt --check`, `cargo check`, `cargo test`, `cargo clippy --all-targets -- -D warnings` et `git diff --check` restent verts.
