# Sylloge 0.3.0 — notes de release de test

> À publier seulement après la construction locale d’artefacts signés et la vérification de leurs noms, signatures et URLs. Ce fichier n’est pas une GitHub Release créée.

## Nouveautés

- Accueil éditorial pour Films locaux : vus récemment, favoris, films en attente ou ajoutés récemment, calendrier de visionnage.
- Paramètres organisés en Profils, Données et sauvegardes, Application et À propos.
- Sauvegardes, export et import regroupés dans les Paramètres.
- Version installée lue depuis le runtime Tauri.
- Chaîne d’updater Tauri : vérification manuelle, préférence de recherche automatique, report, ignorance et installation d’une release GitHub signée.

## Première installation macOS

Télécharger le DMG de cette release, ouvrir le fichier puis placer `Sylloge.app` dans le dossier Applications. Cette première installation est manuelle : l’updater devient utile à partir de la version supérieure publiée et signée avec la même clé Tauri.

Sylloge n’est pas encore signée avec un Developer ID Apple. macOS peut donc demander une validation explicite dans Réglages Système → Confidentialité et sécurité lors de l’ouverture initiale.

## Limites connues

- Films uniquement ; les autres médiums ne sont pas encore implémentés.
- La mise à jour automatique ne peut être prouvée qu’après publication d’une version supérieure signée.
- La base SQLite locale n’est ni synchronisée ni déplacée par l’installation ou l’updater.
